**c. Desain UI**

Tema: CRT Console / Retro Handheld — terinspirasi dari estetika Game Boy.

Setiap halaman dirender di dalam layar CRT teal gelap yang tertanam di badan konsol plastik. Teks menggunakan warna phosphor hijau dengan efek glow. Tombol-tombol berbentuk kotak dengan shadow solid yang bisa ditekan (sinking effect). Terdapat efek scanline, vignette sudut layar, dan boot sequence saat membuka layar.
